# Node-RED Flows

This directory contains the Node-RED flow configurations for the Wat Doi Monitoring System.

## How to use:
1.  Export your Node-RED flows as JSON files (e.g., `flows.json`) and place them here.
2.  **Important:** If your flows contain sensitive credentials, ensure `flows_cred.json` is handled securely and is **NOT** committed to this repository. Consider using environment variables for credentials.
3.  To deploy these flows, copy the `.json` files to your Node-RED user directory (e.g., `~/.node-red/`) and restart Node-RED.
